Welcome to the Pit

You are looking at the PIT — your personal workspace for learning how to program an FTC robot. Before you write any code, let's take a quick tour so you know where everything is and how it works.

What You See On Screen

Left — LESSONS. This panel, which you're reading right now. It walks you through each lesson step by step and links straight into your code so you always know where to look.

Right, top — CODE EDITOR. This is where you write the Java code that controls the robot — line numbers, syntax coloring, and file tabs across the top. The row of buttons above it (Build & Init, Start, Stop) is how you load your code onto the robot and run it.

Right, bottom — TEST STAND. A small 3D preview of your robot sitting on a bench, just like a real pit table at competition. Drag to orbit the camera around it. Once your code is running you can drive and watch the mechanisms move without ever leaving the Pit.

There's also a separate DRIVER HUB tab near the top of the screen. In real FTC, the Driver Hub is the Android tablet drivers use to control the robot during a match. It has the exact same Build & Init / Start / Stop controls — you won't need it for lessons, but it's there when you're ready to run a real match.

What Is a Code Package?

A code package is your personal folder of Java files — think of it as your own copy of the robot's brain. You already have one called starter selected and ready to go, right above the code editor. As you complete lessons, you'll add code to it and the robot will learn new abilities — driving, running mechanisms, tracking its position, and more.

Key Idea

You can make additional packages any time with the + Package button — handy for trying something risky without touching your main code. Switch between packages with the dropdown.

The Edit → Build & Init → Run Loop

Every time you change code, you'll follow the same three steps:

  • Edit — type or change code in the editor.
  • Build & Init — click the button above the editor. This saves your code, compiles it, and loads it onto the robot. If there's a mistake, you'll see an error message instead.
  • Run — click Start to run your program, Stop to stop it.

You'll do this loop dozens of times. It becomes second nature fast.

What About the Robot?

Right now, your robot does not drive. That's on purpose — the starter code already knows about its motors and how to read the gamepad, but there are no driving instructions yet. You'll add them piece by piece: early lessons wire up driving and basic feedback, later lessons add mechanisms and sensors. By the end, you'll have a fully working robot you built yourself, one lesson at a time.

Navigating Lessons

Every lesson uses the same colored blocks — you'll see them explained at the top of the page, right below the title. Some lessons also have a clickable link that jumps the code editor straight to the right spot, so you always know exactly where to type.

To Do
  • Reset Lesson Code, at the top of every lesson, puts your code back to exactly how it should look at the start of that lesson. Use it if you get stuck.
  • Mark Complete, at the bottom of every lesson, checks it off so you can move on.

Backing Up Your Work

Your code package lives in this browser. If you want a backup, or want to share it with someone else's computer, use Export next to the package dropdown to save it as a .zip, and Import to load one back in later.
