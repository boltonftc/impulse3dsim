Add these pieces to your code package only if your robot has the two-wheel CR-servo extractor, and not the Extractor Arm. (Thanks to the try/catch, the code is safe on a robot without the servos, and it compiles and runs in the simulator, where telemetry shows ON/OFF.)

🔓 1. New file: AltExtractor.java⩢ Copy
package org.firstinspires.ftc.teamcode;

import com.qualcomm.robotcore.hardware.CRServo;
import com.qualcomm.robotcore.hardware.DcMotorSimple;
import com.qualcomm.robotcore.hardware.HardwareMap;

/*
 * AltExtractor -- the alternate pollen extractor: two CR servos on the front of the robot,
 * mirror-mounted, that spin together to pull pollen in. Tap D-pad down to start, tap again to stop.
 * (An ALTERNATIVE to the Extractor Arm -- a robot has one or the other.)
 *
 * Driver Hub configuration: two "Continuous Rotation Servo" devices named
 *   extractor_left  and  extractor_right
 */
public class AltExtractor implements Subsystem {

    private static final double RUN_POWER = 1.0;   // full speed while running

    private final CRServo left;      // null if this robot has no alt extractor
    private final CRServo right;
    private boolean running = false; // does the driver WANT the wheels spinning?

    public AltExtractor(HardwareMap hardwareMap) {
        CRServo foundLeft = null;
        CRServo foundRight = null;
        try {
            foundLeft  = hardwareMap.get(CRServo.class, "extractor_left");
            foundRight = hardwareMap.get(CRServo.class, "extractor_right");
        } catch (IllegalArgumentException e) {
            foundLeft = null;    // either one is missing: run without the extractor
            foundRight = null;
        }
        left = foundLeft;
        right = foundRight;
        if (hasExtractor()) {
            right.setDirection(DcMotorSimple.Direction.REVERSE);  // mirror-mounted
            left.setPower(0.0);                                   // start stopped
            right.setPower(0.0);
        }
    }

    private boolean hasExtractor() {
        return left != null && right != null;
    }

    /** Start the wheels (autos use this). */
    public void on()     { running = true; }

    /** Stop the wheels (autos use this). */
    public void off()    { running = false; }

    /** Flip: on if off, off if on (TeleOp uses this, with edge detection). */
    public void toggle() { running = !running; }

    /** True while the wheels are supposed to be spinning -- for telemetry. */
    public boolean isRunning() { return running; }

    @Override
    public void update() {
        if (!hasExtractor()) {
            return;                                   // no extractor on this robot
        }
        double power = running ? RUN_POWER : 0.0;     // ON: run power, OFF: stop
        left.setPower(power);
        right.setPower(power);
    }
}

Make it yours
  • Configuration: two Continuous Rotation Servo devices named extractor_left and extractor_right.
  • Wrong way? Both push out: reverse left instead of right. One in, one out: remove the reverse line.
  • Too strong or too fast? Lower RUN_POWER (try 0.6).
  • Two drivers? Use gamepad2.dpad_down so the second driver runs it.
  • Want reverse later? Change boolean running into an enum (FORWARD, OFF, REVERSE), like the Intake, add a reverse() command, a switch in update(), and map D-pad up to it.
