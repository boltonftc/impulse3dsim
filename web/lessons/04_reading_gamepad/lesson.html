Reading the Gamepad

Telemetry lets your robot talk. Now it needs to listen. Every button press and stick nudge a driver makes shows up in one place: gamepad1. In this lesson you'll read two of those inputs, park them in variables, and watch the numbers move as you touch the controller.

A variable is a labeled box

A variable is a named box that holds one value. Before you use a box, you say what kind of value goes in it — its type:

  • double holds a number with a decimal point. A stick axis is a double: it slides smoothly from -1.0 to 1.0. Each stick has two axes — an x (left/right) and a y (up/down).
  • boolean holds just true or false. A button is a boolean: it's either pressed or it isn't.

Step 1 — Read both sticks and the buttons

Inside the run loop there's a labeled spot for this. Go to it and read every input you'll need later: both sticks (X and Y) and all four face buttons, then show them on telemetry. You'll reuse these lines as you start driving, so grab them all now.

▸ Go to Gamepad : Read
Type this code⧉ Copy
double leftStickX = gamepad1.left_stick_x;
double leftStickY = gamepad1.left_stick_y;
double rightStickX = gamepad1.right_stick_x;
double rightStickY = gamepad1.right_stick_y;
boolean aHeld = gamepad1.a;
boolean bHeld = gamepad1.b;
boolean xHeld = gamepad1.x;
boolean yHeld = gamepad1.y;
telemetry.addData("Left Stick X", leftStickX);
telemetry.addData("Left Stick Y", leftStickY);
telemetry.addData("Right Stick X", rightStickX);
telemetry.addData("Right Stick Y", rightStickY);
telemetry.addData("A", aHeld);
telemetry.addData("B", bHeld);
telemetry.addData("X", xHeld);
telemetry.addData("Y", yHeld);
What each line does
  • gamepad1.left_stick_x / left_stick_y are the left stick's left-right and up-down positions, read fresh every loop. The right stick works the same way. Each goes into its own double box.
  • gamepad1.a (and b, x, y) is true while that face button is held. Each goes into its own boolean box.
  • The addData lines show every box on the Driver Hub, right next to the Status and Loops lines from last lesson.
To Do
  • Press Build & Init, then Start.
  • Move both sticks around and watch all four axis values change.
  • Tap A, B, X, and Y and watch each flip between true and false.
Notice: up is negative

Push the left stick up and Left Stick Y goes negative. That surprises everyone. On a gamepad, forward on a stick reads as a negative number — that's just how the hardware reports it. Remember it: when you start driving next lesson, you'll flip that sign so "stick up" means "drive forward."

Hint

If the build fails, check that each line ends with a semicolon ;, and that the types match: a stick goes in a double, a button goes in a boolean. If the values never change, make sure your lines are inside the while (opModeIsActive()) braces so they run every loop.

You can now read the driver. A stick is just a number and a button is just true-or-false — and next lesson those numbers become motor power, and the robot finally moves.
