Path Capture

Hold C (or controller LT) to record a pose. Press 1/2/3/4 (or controller A/B/X/Y) to mark an action — that ends the current path chain and starts a new one. Drag a pose disc to move it, drag its arrow tip to re-aim it, or edit x/y/h directly in the list below. The cyan ▲ Start marker is the robot's initial Pinpoint pose (where you place it before the match) — drag/edit it like any pose. Generated files have // CAP:... marker comments — leave those in place (add your own code below a // CAP:ACTION line, above its matching // CAP:ACTION-END) if you want to re-open the file here later; if the markers get removed or broken, this tool will refuse to load it back in rather than guess and lose your edits.
